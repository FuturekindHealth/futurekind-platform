# Contributing to FutureKind

Thank you for contributing to FutureKind.

Our mission is to build the world's most trusted open-source AI platform for healthcare.

## Core Principles

Every contribution should improve at least one of the following:

- Patient safety
- Clinical workflow
- Reliability
- Security
- Performance
- Documentation

## Pull Request Checklist

Before opening a Pull Request:

- [ ] Documentation updated
- [ ] Security considered
- [ ] Logging added (where applicable)
- [ ] Health checks included
- [ ] Configuration documented
- [ ] No secrets committed
- [ ] Clinical impact documented (if applicable)

## Code Style

- Keep code simple.
- Keep modules independent.
- Prefer readability over cleverness.
- Prefer explicit behavior over hidden magic.

## Clinical Safety

FutureKind assists clinicians.

FutureKind never replaces clinical judgment.

## Community

Be respectful.

Be constructive.

Assume good intent.

We build together.
